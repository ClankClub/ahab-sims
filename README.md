# ahab-sims

Throwaway Ahab homes left behind by `scripts/simulate_sessions.py`, which runs the real Ahab heartbeat and session code against a fake clock and a fake or real model, to see how its running session behaves over days and months. Each folder is one simulated home: `memory.db` is the database, `events.log` is its event log as plain text. `gibberish-run/` was two simulated days with a fake model that writes random words, so the text means nothing; only the sizes and structure are real.
