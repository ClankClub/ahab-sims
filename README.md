# ahab-sims

Throwaway Ahab homes left behind by `scripts/simulate_sessions.py`, which runs the real Ahab heartbeat and session code against a fake clock and a fake or real model, to see how its running session behaves over days and months. Each folder is one simulated home: `memory.db` is the database, `events.log` is its event log as plain text. `gibberish-run-2-days/` was two simulated days with a fake model that writes random words, so the text means nothing; only the sizes and structure are real. `mistral-nemo-1-day/` was one simulated day with Mistral Nemo (12B, via OpenRouter) playing the agent against a scripted owner; it has its run report and raw numbers too. Nemo often dropped the reply format Ahab needs, and a filter somewhere on its path turned some names into `[ADDRESS]`. `muse-spark-1.3-contributor-1-day-100k/` was one day with Meta's Muse Spark 1.3 Contributor (it keeps the facts in its notes but breaks the reply format about once a wake), and `deepseek-v4.1-flash-low-3-hours-100k/` was three hours with DeepSeek V4.1 Flash on low reasoning (clean format, under a cent). Both used a 100k-token session. The same placeholder filter showed up on both.
